Wynik podziału

Kliknij przycisk po lewej, aby przetestować warunek podziału. Algorytm sprawdza setki takich podziałów i wybiera najlepszy.

Implementacja (pseudo-kod sklearn):

def build_tree(data, depth):
  if depth == MAX_DEPTH or is_pure(data):
    return Leaf(majority_class(data))
    
  best_feature, best_threshold = find_best_split(data) # Minimalizuje Gini
  left_data, right_data = split(data, best_feature, best_threshold)
  
  node = Node(best_feature, best_threshold)
  node.left = build_tree(left_data, depth+1)
  node.right = build_tree(right_data, depth+1)
  return node

2. Gini Impurity (Uczenie Maszynowe) vs Współczynnik Giniego (Socjologia)

Węzeł w drzewie (Gini Impurity)

Oblicza ryzyko, że losowy element z węzła zostanie źle sklasyfikowany, jeśli przypiszemy mu klasę losowo zgodnie z rozkładem w węźle.

$$Gini = 1 - \sum_{i=1}^{k} p_i^2$$

Gdzie $p_i$ to odsetek klasy $i$ w węźle. Zakres to [0.0, 0.5] dla dwóch klas.

Nierówności dochodowe (Krzywa Lorenza)

W socjologii to miara rozwarstwienia. Pole pod krzywą idealnej równości ($A$) przez całkowite pole ($A+B$).

$$G = \frac{A}{A+B}$$

Zakres [0.0, 1.0]. 0 to idealny komunizm majątkowy, 1 to pełen monopol (jeden człowiek ma wszystko).

Wylicz Gini dla przykładowego węzła

3. Las Losowy jako klasyfikator nieliniowy

Użytkownicy często pytają: Czy Lasy mogą być nieliniowe, skoro pojedyncze drzewo dzieli przestrzeń tylko liniami prostymi (wertykalnie/horyzontalnie)? TAK. Agregacja (Bagging) wielu "kwadratowych" i "schodkowych" granic decyzyjnych prowadzi do wygładzenia i tworzy złożone, nieliniowe kształty.

Wizualizacja przestrzeni decyzyjnej
